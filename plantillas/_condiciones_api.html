{# Condiciones de uso del widget y de la API (se incluyen en /widget/ y /api/). #}

Condiciones de uso

  • Gratis: puedes usar el widget y la API sin costo en sitios y proyectos personales, educativos y comerciales, sin registrarte.
  • Con atribución: muestra junto a los datos un enlace visible a {{ sitio.nombre }} ({{ sitio.url }}/). El código del widget ya lo incluye: no lo ocultes ni lo elimines. El enlace puede llevar rel="nofollow"; el del widget ya viene así.
  • Sin alterar los datos: no modifiques los valores ni los presentes como propios.
  • Valores referenciales: se entregan tal cual, sin garantía de exactitud ni de disponibilidad. Antes de usarlos en un pago, contrato o declaración, verifícalos en el Banco Central de Chile, el SII o el INE.
  • Uso razonable: si consultas la API desde un servidor, guarda las respuestas en caché (por ejemplo, 30 minutos) en vez de pedirlas en cada visita.
  • Cambios: podemos mejorar el widget, cambiar el servicio o suspenderlo si detectamos abusos. Si una mejora de la API no fuera compatible con la actual, la publicaremos como una versión nueva (/api/v2/) y lo avisaremos en esta página.

Estas condiciones complementan los términos de uso del sitio.
