Indicadores del día

GET {{ cortable(url_api ~ 'indicadores.json') }}

{{ ejemplo_indicadores }}
  • uf: UF de hoy y, en manana, la de mañana (o null si aún no se conoce). La UF se conoce por adelantado hasta el día 9 del mes siguiente.
  • dolar y euro: último valor publicado por el Banco Central, con su fecha. Se publican solo en días hábiles. euro es null si no hay un dato reciente.
  • utm: UTM del mes indicado en mes.
  • ipc: último IPC publicado por el INE: variacion_porcentual es la variación mensual en porcentaje (0.4 significa 0,4%).
  • actualizado: fecha y hora (de Chile) de nuestra última actualización de los datos.

Ejemplos de uso

JavaScript (navegador o Node.js)

fetch("{{ url_api }}indicadores.json")
  .then(function (respuesta) { return respuesta.json(); })
  .then(function (datos) {
    console.log("UF de hoy:", datos.uf.valor);
    console.log("Dólar observado del " + datos.dolar.fecha + ":", datos.dolar.valor);
  });

curl

curl -s {{ url_api }}indicadores.json
curl -s {{ url_api }}feriados/{{ hoy.year }}.json

Python

import json
from urllib.request import Request, urlopen

URL = "{{ url_api }}uf.json"
pedido = Request(URL, headers={"User-Agent": "mi-aplicacion/1.0"})
with urlopen(pedido, timeout=10) as respuesta:
    uf = json.load(respuesta)

for punto in uf["serie"][-3:]:
    print(punto["fecha"], punto["valor"])

Identifica tu aplicación con un User-Agent propio: algunos filtros de seguridad bloquean los clientes que no lo envían.

Frecuencia de actualización

Los archivos se regeneran dos veces al día, en la mañana y en la tarde (hora de Chile), con los datos del Banco Central de Chile, el SII y el INE. Las respuestas se pueden guardar en caché por 30 minutos (Cache-Control: public, max-age=1800). El dólar observado y el euro cambian solo en días hábiles; la UTM, una vez al mes, y el IPC, cuando el INE lo publica (cerca del día 8 de cada mes).

Atribución requerida

Puedes usar los datos gratis, también en proyectos comerciales, siempre que muestres junto a ellos un enlace visible a {{ sitio.nombre }}. Por ejemplo:

<p>Fuente: <a href="{{ sitio.url }}/">{{ sitio.nombre }}</a></p>

Si tu sitio lo prefiere, el enlace puede llevar rel="nofollow".

Valores referenciales. Los datos provienen de fuentes oficiales, pero pueden tener errores o atrasos. Antes de usarlos en un pago, contrato o declaración, verifícalos en el Banco Central de Chile, el SII o el INE.
